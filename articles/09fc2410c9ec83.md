## Q1
アクセス数を数えなさい。

### Q1の答え
:::details 答えと解説
```bash:アクセス数を数える
$ wc -l access.log
```

`wc`コマンドはテキストファイルの行数、単語数、文字数、バイト数をカウントするコマンドです。

```bash:オプションなしの例
$ wc sample.txt
  10  50 300 sample.txt  # 10行、50単語、300バイト
```

`-l`オプションは行数のみを出力します。

`-l`はline（行）の略です。
:::

## Q2
HTTPステータスコード`404`の行だけ抽出しなさい。

### Q2の答え
:::details 答えと解説
```bash:HTTPステータスコード404の行を抽出
$ grep ' 404 ' access.log
```

`grep`コマンドはファイルや標準入力から特定の文字列やパターンにあてはある行を検索するコマンドです。
&nbsp;

```bash:grepコマンド
$ grep [オプション] 検索パターン [ファイル名]
```
&nbsp;

```bash:HTTPステータスコード404の行を抽出
$ grep ' 404 ' access.log
```
&nbsp;

上の例だと、`access.log`の中から`404`を含む行だけを検索して表示するコマンドです。
:::

## Q5
最もアクセス数が多いIPを調べなさい。

### Q5の答え
:::details 答え
```bash:最もアクセス数が多いIPを検索
$ awk '{ print $1 }' access.log | sort | uniq -c | sort -nr
```
:::

:::details 解説 その1
### sortコマンド

sort は文字列を辞書順で並び替えるコマンドです。
&nbsp;

`sort`コマンドは非常に強力で、ログ解析やデータ整理でもよく使われます。
&nbsp;

`sort`コマンドにはさまざまなオプションがあります。
&nbsp;


今回は`-n`と`-r`を使いました。（その省略形の`-nr`を使用。）
&nbsp;

`-n`は数値としてソートを行うオプションです。
&nbsp;

`-r`は逆順にソートを行うオプションです。
&nbsp;

興味のある方は下のオプション一覧を見てみてください。

:::details オプション一覧
| オプション | 説明 | 使用例 |
| ---- | ---- | ---- |
| `-n` | 数値順にソート | `sort -n score.txt` |
| `-r` | 逆順にソート | `sort -r names.txt` |
| `-u` | 重複削除 | `sort -u users.txt` |
| `-k [列番号]` | 列指定しソート | `sort -k 2 users.txt` |
| `-t [区切り文字]` | 区切り指定 | `sort -t , -k 2 users.txt` |
| `-V` | バージョン順 | `sort -V versions.txt` |
:::

:::details 解説　その2
### uniqコマンド

uniqコマンドは重複行を削除してくれるコマンドです。

なので、下のような`sample.txt`を
```txt:sample.txt
Apple
Apple
Banana
Banana
Banana
Chocolate
```

重複がないよう、出力してくれます。

```bash:出力

$ uniq sample.txt
# ------- ↓出力↓ ------- #
Apple
Banana
Chocolate
```
`-c`オプションは重複が何個あるかを教えてくれます。

```bash:出力
$ uniq -c sample.txt
# ------- ↓出力↓ ------- #
2 Apple
3 Banana
1 Chocolate
```
&nbsp;


Appleであれば、重複が2つ、Bananaであれば、重複が3つとなります。
&nbsp;


ただし、uniqには気をつけるべき点があります。

それは、**連続していなければ、重複を取り除かない**ということです。
&nbsp;


つまり、
```txt:sample.txt
Apple
Banana
Apple
```
上のテキストファイルに
```bash:uniqコマンド
$ uniq sample.txt
```
としても、

```txt:sample.txt
Apple
Banana
Apple
```
変更がありません。
&nbsp;


#### 対策
`sort`コマンドを使い並び変えましょう！！

```bash:sortコマンドで並び替え
$ sort sample.txt
# ------- ↓出力↓ ------- #
Apple
Apple
Banana
```
`sort`コマンドで並び替えをした後、`uniq`コマンドを使うことで、

```bash:重複行削除
$ sort sample.txt | uniq
# ------- ↓出力↓ ------- #
Apple
Banana
```
