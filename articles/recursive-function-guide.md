# 対象読者
- 再帰関数が何かなんとなくわかる
- 階乗・フィボナッチ数などありきたりな再帰関数の実装は理解できる
- 実践的なものになると途端に実装できなくなる

# 編集前記
わけあって `Erlang` という関数型言語を学んでいます。

一般に関数型言語では、 `for` 文や `while` 文というものは存在しません。

その代わりに再帰関数を使って `for` 文や `while` 文で書ける処理を実装します。

```python:sample.py
arr = [1, 2, 3]
for i in range(n):
    print(arr[i])
```

上のような簡単な `Python` コードも、関数型言語だと `for` 文が使えないため、再帰関数で
実装するしかありません。 

以降は関数型言語から学んだ再帰関数の実装方法を共有します。

# 再帰関数の例
```python:sample.py
arr = [1, 2, 3]
for i in range(n):
    print(arr[i])
```

上のコードを再帰関数で書くと
```python:recursive_for.py
def func_for(_list):
    if len(_list) == 0:
        print("PROCESS DONE")
        return
    print(_list[0])
    func_for(_list[1:])

func_for([1, 2, 3])
# ---- 出力 -----
# 1
# 2
# 3
# PROCESS DONE
```
となります。

# どうやって考える？
上の再帰関数の例をどうやって読めば良いでしょうか？

実際に処理を追って見ましょう！！

1. `func_for([1, 2, 3])` を呼び出している。
2. 引数の配列の最初の要素 `1` が出力され、 `func([2, 3])` が実行される。
3. `func([2, 3])` が動作する。
4. 引数の配列の最初の要素 `2` が出力され、 `func([3])` が実行される。
5. `func([3])` が動作する。
6. 引数の配列の最初の要素 `3` が出力され、 `func([])` が実行される。
7. 引数の配列の長さは0なので、 `PROCESS DONE` が出力される。

つまり、
```
func([1, 2, 3])
        ↓
func([2, 3])
    ↓
func([3])
    ↓
func([])
```

のように、問題が小さくなり、最終的にベースケースに辿り着き、終了します。

### ただし、もっと複雑な再帰関数では毎回全て追うのは大変

- 木構造の探索
- ディレクトリの再帰的な探索
- DFS

などでは再帰関数が活躍します。

このような複雑なことをする中で

「今は`func(A)` が呼ばれて、次は `func(B)` が呼ばれて、その次は ...」

だと処理を追うのは非常に大変です。

# もっといい方法で再帰関数を考えよう
関数 `func_for` が何を出力するかをまず確定させましょう。

この場合、関数 `func_for` は配列の要素を先頭から順番に出力し、最後に `PROCESS DONE` を表示する関数です。

つまり、関数 `func_for` は**配列の最初の要素を出力する関数**だと思います。

具体的に関数の引数に応じて中身を追うなどしなくていいです。

関数が**どんな処理をするか**だけを考えましょう。

その上で考えます。

1. まず、引数の配列の最初の要素を出力
2. 配列の最初の要素は出力したため、先頭を無くした新しい配列を作る（ここでは `_list[1:]`）
3. 新しい配列 `_list[1:]` に対し、関数 `func_for` を呼び出す
4. 1 ~ 3を繰り返し、配列が空になったら、`PROCESS DONE` と出力する

このようにすれば、再帰関数の中身を具体的に追わずとも、実装できると思います。
